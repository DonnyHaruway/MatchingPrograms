# 安定マッチング反例探索（企業1・労働者3）

企業数1、労働者数3の問題をランダムに生成し、可能なマッチングを全列挙して、安定マッチングが1つも存在しない反例を探索する。

同僚選好は対称な二値選好とし、両立可能なペアを `0`、両立不可能なペアを `-INF` で表す。各労働者について企業と未マッチのどちらを好むかをランダム化し、企業についても3人の労働者と空席を含む厳密な選好をランダム化する。企業の既定の定員は2である。

可能なマッチングの列挙には既存の `MatchingSystem::make_all_matchings()` を利用する。安定性は、今回のモデルで定義した実現可能性、個人合理性、タイプ1ブロッキングペア、タイプ2ブロッキングペアを直接判定する。

## ビルド

`programs` ディレクトリで以下を実行する。

```sh
cmake -S experiments/stable -B build/stable
cmake --build build/stable -j
```

## 10万回のランダム探索

```sh
./build/stable/search_stable_counterexample \
  --trials 100000 \
  --seed 20260828 \
  --capacity 2
```

乱数シードを変える場合は `--seed`、企業の定員を変える場合は `--capacity` を変更する。

## 制限した問題領域の全探索

労働者の選好 $2^3$ 通り、企業の厳密な選好 $4!$ 通り、3組の労働者ペアに対する両立可能・不可能の組合せ $2^3$ 通り、合計1,536通りを全探索できる。

```sh
./build/stable/search_stable_counterexample --exhaustive --capacity 2
```

反例が見つかった場合は、企業の選好と両立不可能なペアの集合を表示する。反例の有無にかかわらず、探索が正常に完了した場合の終了コードは0である。

## 確認結果

シード `20260828`、定員2で10万回実行したところ、1,536種類の問題がすべて出現したが、安定マッチングが存在しない反例は見つからなかった。また、定員1、2、3のそれぞれについて1,536通りを全探索した場合も反例は見つからなかった。

## 企業2・労働者3の探索

企業を2社に増やし、定員を $(q_{f_1},q_{f_2})=(2,1)$ として探索する。反例を発見すると、実現可能かつ個人合理的な各マッチングと、それをブロックするタイプ1またはタイプ2ブロッキングペアを表示する。

ビルド、10万回の探索、全出力のtxt保存は、次のシェルスクリプトだけで実行できる。

```sh
./experiments/stable/run_search_2x3.sh
```

出力は `experiments/stable/outputs/` に保存され、同時にターミナルにも表示される。既定では実現不可能なペアをちょうど1組に固定する。ファイル名には不可能ペア数、試行回数、乱数シード、実行日時が含まれる。

```text
counterexample_2x3_pairs1_trials100000_seed20260828_20260828_153000.txt
```

既存ファイルは上書きしない。同じ条件の実行が同じ秒に重なった場合は、ファイル名の末尾に `_1`、`_2` のような連番が付く。第1引数で試行回数、第2引数で乱数シード、第3引数で不可能ペア数、第4引数で `random` または `exhaustive` を指定できる。

```sh
./experiments/stable/run_search_2x3.sh 100000 20260828 1
```

不可能ペアがちょうど1組の全問題を列挙する場合は、次のように実行する。

```sh
./experiments/stable/run_search_2x3.sh 100000 20260828 1 exhaustive
```

### 不可能ペアが1組の場合の結果

企業2、労働者3、定員 $(2,1)$ を維持し、不可能ペアをちょうど1組に固定して10万回のランダム探索を行ったが、反例は見つからなかった。さらに、労働者の選好 $6^3$ 通り、企業の選好 $24^2$ 通り、不可能ペアの選択3通りからなる全373,248問題を列挙したが、安定マッチングが存在しない問題はなかった。

したがって、この問題サイズと定員の下では、不可能ペアが1組だけの反例は存在しない。

### 不可能ペアが2組の反例

不可能ペア数を固定しない探索では、シード `20260828` の19,636件目で、不可能ペアを2組持つ反例が得られた。反例の選好と全マッチングの検証は [`counterexample_2x3.md`](counterexample_2x3.md) に記録している。上記の全探索結果と合わせると、この反例は不可能ペア数の意味で最小である。
