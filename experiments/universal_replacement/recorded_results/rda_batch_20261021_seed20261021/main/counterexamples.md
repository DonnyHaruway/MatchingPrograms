# 企業告白型RDAの反例

[全体の集計](report.md)

各選好条件から探索ノード数が最小の反例を選び、同数なら試行番号が小さいものを掲載する。図は生成せず、元の入力と1本の不安定な経路を示す。

分類: `mixed`。全2経路のうち、UR安定1、UR不安定1。

| f1 | w8 > w5 > w7 > w6 > w4 > w2 > w3 > w1 |
| f2 | w7 > w2 > w4 > w5 > w1 > w6 > w8 > w3 |

| f5 | w6 > w7 > w8 > w5 > w2 > w1 > w3 > w4 |

| 労働者 | 順位 |
|---|---|
| w1 | f1 > f3 > f2 > f4 > f5 |
| w2 | f4 > f1 > f2 > f3 > f5 |
| w3 | f4 > f3 > f1 > f5 > f2 |
| w4 | f5 > f4 > f1 > f3 > f2 |
| w5 | f3 > f5 > f1 > f2 > f4 |
| w6 | f2 > f5 > f4 > f3 > f1 |
| w7 | f3 > f2 > f5 > f4 > f1 |
| w8 | f5 > f2 > f3 > f1 > f4 |

禁止ペア: (w1,w2)、(w2,w4)、(w2,w5)、(w2,w6)、(w2,w7)、(w4,w5)、(w5,w8)、(w6,w7)、(w7,w8)。

### 不安定な経路

| 順番 | 違反ペア | 削除 | 相方の所属：親→直後→終点 |
|---|---|---|---|
| 1 | f1: (w4,w5) | f1からw4 | w5: f1 → f3 → f3 |

| 終点の企業 | 所属労働者 |
|---|---|
| f1 | {w1} |
| f2 | {w4, w6} |
| f3 | {w5, w7} |
| f4 | {w2, w3} |
| f5 | {w8} |
| 未マッチ | ∅ |

削除後の選好ではUR安定。元の選好では以下のUR逸脱ペアがある。

- **(f1,w4)**: w4はf2よりf1を厳密に好む。
  f1に空席があり、追加は企業の評価を改善し、追加後の同僚制約も満たす。
